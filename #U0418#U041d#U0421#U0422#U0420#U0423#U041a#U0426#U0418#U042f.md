# Как подключить общую таблицу игроков (5 минут, бесплатно)

Сейчас результаты хранятся в памяти каждого телефона, поэтому на большом экране их не видно.
Нужна общая база. Самая простая — Firebase Realtime Database.

1. Откройте https://console.firebase.google.com и войдите аккаунтом Google.
2. «Создать проект» → любое имя (например, museum-quiz). Google Analytics можно отключить.
3. Слева: Сборка (Build) → **Realtime Database** → «Создать базу данных». Регион любой, режим — «Тестовый» (потом мы заменим правила).
4. Откройте вкладку **Правила** и вставьте это вместо всего текста, нажмите «Опубликовать»:

```json
{
  "rules": {
    "quiz": {
      ".read": true,
      "$id": {
        ".write": "!data.exists()",
        ".validate": "newData.hasChildren(['name','score','right','t']) && newData.child('name').isString() && newData.child('name').val().length <= 16 && newData.child('score').isNumber() && newData.child('score').val() >= 0 && newData.child('score').val() <= 2000"
      }
    }
  }
}
```
   Эти правила разрешают всем читать таблицу и добавлять новые результаты, но не менять и не удалять чужие, и не принимают очки больше 2000.

5. Вкладка **Данные**: сверху будет адрес вида `https://museum-quiz-12345-default-rtdb.firebaseio.com`. Скопируйте его.
6. Откройте `config.js` и вставьте адрес между кавычек:
   `const MUSEUM_DB_URL = "https://museum-quiz-12345-default-rtdb.firebaseio.com";`
7. Загрузите все файлы на Netlify заново (перетащите папку целиком).

Готово: имена и очки со всех телефонов появятся на слайде «Игра».

# Как добавить фото и видео

1. Положите файлы в папку `media/` (фото .jpg/.png/.webp, видео .mp4).
2. В начале `script.js` найдите список `MEDIA` и добавьте строки:
```js
const MEDIA=[
  {src:"media/hall1.jpg", cap:"В зале археологии"},
  {src:"media/tour.mp4", cap:"Идём по залу"},
  {src:"https://www.youtube.com/watch?v=XXXXXXXXXXX", cap:"Видео с экскурсии"},
];
```
3. Загрузите сайт на Netlify заново.

Советы: фото лучше сжать до 300–500 КБ, видео — до 20–30 МБ (или загрузить на YouTube и вставить ссылку).


# Подключение статистики Google Forms на новой странице «Статистика опроса»

Важно: ссылка на саму Google Форму не даёт сайту доступа к ответам. Поэтому на странице есть поле ссылки на форму и отдельное поле опубликованной CSV-таблицы ответов.

1. Откройте Google Форму → вкладка «Ответы» → значок Google Таблиц, чтобы создать/открыть таблицу ответов.
2. В таблице выберите **Файл → Поделиться → Опубликовать в интернете**.
3. Выберите лист с ответами и формат **CSV**, затем нажмите «Опубликовать» и подтвердите действие.
4. Скопируйте ссылку публикации CSV и вставьте её в поле «Ссылка на CSV таблицы ответов Google Sheets» на странице «Статистика опроса».
5. В поле «Ссылка на Google Форму» вставьте обычную ссылку для заполнения опроса. Нажмите «Загрузить статистику».

Сайт покажет количество строк-ответов и распределение значений по столбцам. Если в форме собираются персональные данные, не публикуйте таблицу целиком: создайте отдельный лист с обезличенными данными или используйте защищённый Apps Script endpoint. Публичная публикация делает данные доступными всем, у кого есть ссылка.

Если браузер блокирует CSV-запрос (CORS), нужен Apps Script endpoint или серверная интеграция; обычная ссылка Google Forms не позволяет обойти это ограничение.


# Исправление Failed to fetch: подключение статистики без CORS

Ошибка возникала потому, что браузер не разрешает странице напрямую скачивать CSV с Google Sheets в некоторых случаях (CORS). Обновлённый скрипт сайта использует JSONP через Google Apps Script — он не делает прямой `fetch` к таблице.

## Один раз настройте Apps Script

1. Откройте таблицу ответов Google Forms.
2. В адресе таблицы скопируйте её ID: часть URL между `/spreadsheets/d/` и следующим `/`.
3. В таблице выберите **Расширения → Apps Script**.
4. Удалите код в редакторе и вставьте код ниже.
5. В строке `SPREADSHEET_ID` укажите ID своей таблицы. Если ответы находятся не на первом листе, укажите название листа в `SHEET_NAME`.
6. Нажмите **Сохранить** → **Развернуть → Новое развертывание** → выберите тип **Веб-приложение**.
7. «Выполнять как»: **Я**. «У кого есть доступ»: **Все** (название пункта может отличаться).
8. Нажмите «Развернуть», подтвердите разрешения Google и скопируйте URL веб-приложения, заканчивающийся на `/exec`.
9. В сайте вставьте этот URL во второе поле «Ссылка на веб-приложение Google Apps Script», а ссылку формы — в первое. Нажмите «Загрузить статистику».

```javascript
const SPREADSHEET_ID = 'ВСТАВЬТЕ_ID_ТАБЛИЦЫ';
const SHEET_NAME = ''; // пусто = первый лист; или укажите название листа

function doGet(e) {
  const callback = String((e && e.parameter && e.parameter.callback) || '');
  // callback ограничен безопасным именем, чтобы не выполнять произвольный код.
  if (!/^[A-Za-z_$][0-9A-Za-z_$]{0,80}$/.test(callback)) {
    return ContentService.createTextOutput('Invalid callback');
  }

  let payload;
  try {
    const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
    const sheet = SHEET_NAME ? ss.getSheetByName(SHEET_NAME) : ss.getSheets()[0];
    if (!sheet) throw new Error('Лист ответов не найден. Проверьте SHEET_NAME.');
    const values = sheet.getDataRange().getDisplayValues();
    payload = {
      headers: values.length ? values[0] : [],
      rows: values.length > 1 ? values.slice(1) : []
    };
  } catch (err) {
    payload = { error: String(err && err.message ? err.message : err) };
  }

  return ContentService
    .createTextOutput(callback + '(' + JSON.stringify(payload) + ');')
    .setMimeType(ContentService.MimeType.JAVASCRIPT);
}
```

**Приватность:** доступ «Все» означает, что опубликованная статистика доступна посетителям сайта. Код отдаёт все строки выбранного листа, поэтому если там есть имена, электронные адреса или другие персональные данные, сначала создайте отдельный лист только с обезличенными ответами и используйте его. Не передавайте секретные данные через публичный endpoint.


# Статистика опроса — ручное обновление

Страница «Статистика опроса» работает как статичная страница. Google Apps Script, CSV-загрузка и автоматическое подключение удалены. После того как владелец сайта передаст фактические результаты Google Forms, обновите значения KPI и блоки распределения ответов в `index.html`. Для диаграмм используйте классы `.survey-bar` и задавайте CSS-переменную `--pct` с процентом ответа.
